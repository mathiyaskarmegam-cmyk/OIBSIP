# Task 3 – Magazine Layout

## Oasis Infobyte Graphic Design Internship

### Project
**FRAME – Behind the Screen**

### Objective
Design a professional multi-page magazine layout demonstrating editorial design, typography, whitespace, visual hierarchy, and print media principles.

## Theme
Cinema and Filmmaking

The magazine explores the creative process behind filmmaking, including cinematography, filmmaking roles, and the journey from an idea to a finished film.

## Pages

### Page 1 – Cover
**BEHIND THE SCREEN**

Introduces FRAME magazine and explores the art, technology, and people behind filmmaking.

### Page 2 – The Language of Cinema
**MORE THAN JUST A CAMERA**

Explores composition, lighting, and colour in cinematography.

### Page 3 – Filmmaking Team
**BEHIND EVERY GREAT STORY**

Introduces important filmmaking roles including:
- Director
- Cinematographer
- Editor
- Production Designer
- Sound Designer

### Page 4 – Film Process
**HOW A FILM COMES TO LIFE**

Shows the filmmaking process:

Idea → Script → Pre-Production → Shooting → Editing → Release
